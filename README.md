# Introduction to the Propensity ABCD for Lost Samples (PALS)
Many brain imaging studies suffer from data quality problems that can create biases in research studies. PALS enables researchers to adjust analytic models, so researchers can minimize analysis bias. 
## What is PALS?
Propensity ABCD for Lost Samples (PALS), an R shiny application, reduces bias due to data loss via 1) missigness, 2) sampling differences, or 3) quality control. Without PALS, research studies may produce findings with questionable generalizability.
